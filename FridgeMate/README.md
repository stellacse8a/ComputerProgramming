# FridgeMate

Python · Flask · SQLite로 만든 한국어 모바일 우선 냉장고 관리 웹 앱입니다. 외부 API 키나 유료 서비스가 필요하지 않습니다.

## 설치와 실행

Python 3.10 이상에서 저장소 폴더로 이동한 뒤 실행합니다.

```bash
python -m venv .venv
source .venv/bin/activate
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

실행 후 로컬 브라우저 주소창에 `http://127.0.0.1:5000`을 입력하세요. `PORT` 환경변수로 포트를 변경할 수 있습니다. Flask 개발 서버는 로컬 발표용이며 인터넷 공개 배포용이 아닙니다.

이 클라우드 작업에서 준비한 Python은 `/workspace/fridgemate-venv/bin/python`입니다.

## 시연 순서

1. 홈에서 전체 보관 수량과 임박/경과 식품을 확인합니다.
2. **＋ 식품 추가**에서 이름, 분류, 수량 3개, 오늘 또는 이틀 뒤 소비기한, 보관 위치를 입력합니다.
3. **냉장고**에서 해당 칸과 D-day를 확인하고, 식품을 눌러 상세 화면에서 개봉 여부와 위치를 변경합니다.
4. **알림**에서 등록한 식품의 `소비 / 폐기하기`를 펼치고 1개를 소비합니다. 확인 다이얼로그에서 확정합니다.
5. 상세 화면 또는 검색에서 잔여 2개를 확인합니다.
6. 2개를 이유와 함께 폐기하고 알림 하단 처리 이력에서 소비·폐기 기록을 확인합니다.
7. 서버를 종료한 뒤 다시 실행해도 이력과 수량이 유지됩니다.

## 구현된 기능

- 홈 날짜·인사·전체 수량·임박 카드·앞으로 6일 이내 식품
- 냉장실/냉동실/전체 필터, 위·아래 칸 구분, 칸별 소비기한 오름차순
- 식품 등록, 상세 확인, 개봉 여부·보관 위치 수정
- 일부 소비/폐기, 서버 수량 검증, 0개 식품 활성 목록 제외, 원자적 수량/이력/알림 갱신
- 기한 지난 식품의 상세 또는 알림에서 수량과 폐기 이유를 확인한 뒤 정리
- 6일 이내 및 경과 식품의 앱 내 알림, 읽음 상태, 처리 이력
- 일부 처리한 식품은 알림에 남고, 모두 처리하면 활성 알림에서 제외
- 식품명 부분 검색 및 미보유 식품 등록 연결
- 확인 다이얼로그, CSRF 방어, 한국어 반응형 UI

기한은 서버의 `date.today()`를 기준으로 계산합니다. 7일 이상 초록, 3~6일 노랑, 0~2일 빨강, 음수는 별도 ‘기한 지남’ 배지입니다. 날짜가 바뀐 후 화면을 새로고침하면 재계산됩니다. 개봉 여부는 표시 정보이며 임의의 새 소비기한을 계산하지 않습니다.

## 데이터 저장

`instance/fridgemate.sqlite3`에 저장합니다. 첫 실행에만 서버 날짜 기준 샘플 6종을 넣으며, 수량이 모두 0이 되어도 재시작 시 샘플을 다시 넣지 않습니다. 샘플에는 기한 지난 두부와 임박 우유·딸기가 포함됩니다. 초기 상태가 필요하면 서버를 종료하고 DB 파일을 별도로 백업한 다음 삭제하세요. 삭제하면 기존 기록도 사라집니다.

## 범위와 한계

- 제공된 7주차 계획서 PDF와 화면설계 PPT, 8주차 중간과제 PPT를 검토했습니다. 8주차 화면의 회색 카드·검정 선택 칩·빨간 우선 확인 배너·냉장고 단면도·그림형 위치 선택을 반영했습니다. 온도와 문 상태는 실제 연동이 없으므로 원본의 고정 정상 수치를 표시하지 않습니다. 하단에는 기존 요청대로 홈/냉장고/추가/알림을 유지합니다. 390×844 모바일 Chromium에서 홈·냉장고·등록 화면을 렌더링하고 가로 넘침이 없는지 확인했습니다. 등록→위치 선택→소비 확인→잔여 수량→폐기→이력 흐름도 실제 브라우저에서 검증했습니다. 원본과 픽셀 단위 일치는 보장하지 않습니다.
- 영수증 이미지 업로드/OCR, 실제 냉장고 온도 연동, 모바일 푸시 알림은 **미구현**입니다. UI에도 이를 명시하며 인식 성공이나 실제 연동을 가장하지 않습니다.
- 로그인 없는 1인 로컬 시연용입니다. 식품 이름/수량/기한의 등록 후 편집은 이번 범위에 포함하지 않았으며 개봉 여부와 위치는 수정할 수 있습니다.
